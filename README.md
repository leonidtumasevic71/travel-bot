# Just Travel Telegram Bot

Telegram-бот для оформления заявок на подбор тура по сценарию из присланных скриншотов.

## Что уже реализовано

- Приветственное сообщение с баннером и кнопкой «Подобрать тур».
- Согласие на обработку персональных данных перед началом анкеты.
- Выбор страны: Турция, Египет, ОАЭ, Таиланд, Вьетнам, Россия или свой вариант.
- Выбор типа отдыха: пляж, экскурсии, горы или без предпочтений.
- Ввод примерных дат поездки.
- Выбор количества туристов или собственный вариант.
- Ввод бюджета на человека.
- Сбор имени и номера телефона (кнопка отправки контакта или ручной ввод).
- Экран проверки заявки и редактирование ответов.
- Передача готовой заявки менеджеру в Telegram.
- Сохранение анкеты в SQLite и продолжение после перезапуска бота.
- Одно напоминание о незавершённой заявке после заданного количества минут.

## 1. Подготовка

Нужен Python 3.10 или новее.

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Windows CMD:

```bat
.venv\Scripts\activate.bat
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## 2. Настройка токена

1. Откройте официальный Telegram-бот [@BotFather](https://t.me/BotFather).
2. Отзовите ранее опубликованный токен командой `/revoke` и получите новый.
3. Скопируйте `.env.example` в `.env`.
4. Укажите новый токен в `BOT_TOKEN`.

Не отправляйте токен в чаты, не добавляйте `.env` в Git и не публикуйте его на GitHub.

## 3. Запуск

Из корневой папки проекта:

```bash
python bot.py
```

Откройте бота в Telegram и отправьте `/start`.

SQLite-база `data/applications.db` создаётся автоматически. PostgreSQL и Redis для первой рабочей версии не требуются.

## 4. Подключение менеджера @juuusmi

В проекте настроены два способа связи с менеджером:

- **Автоматическая доставка заявок:** заполненная заявка отправляется в личный Telegram-чат менеджера.
- **Прямое обращение клиента:** в приветствии и после отправки заявки клиент видит кнопку «Написать менеджеру», которая открывает личный чат `https://t.me/juuusmi`.

Чтобы бот мог присылать сообщения в личный чат, менеджер должен один раз открыть `@JustravelToursbot` и нажать Start (или отправить `/start`). Затем:

1. Менеджер отправляет боту `/id`.
2. Бот показывает числовой Telegram `chat_id` менеджера.
3. Вставьте это число в `.env` в `MANAGER_CHAT_ID`. Не указывайте здесь `@juuusmi` — Telegram Bot API требует числовой `chat_id` для отправки сообщения.
4. Оставьте `MANAGER_USERNAME=juuusmi` — он используется для кнопки прямого обращения клиентов.
5. Перезапустите бота.

Отдельная публичная группа не нужна. Если `MANAGER_CHAT_ID` не заполнен или указан неверно, бот не отметит заявку как отправленную и сообщит клиенту, что отправка пока не удалась.

## 5. Настройки

- `BRAND_NAME` — название агентства в сообщениях.
- `PRIVACY_POLICY_URL` — ссылка на опубликованную политику конфиденциальности. Не оставляйте фиктивную ссылку.
- `REMINDER_AFTER_MINUTES` — через сколько минут бездействия отправлять напоминание (по умолчанию 60).
- `WELCOME_IMAGE` — путь к баннеру приветствия.
- `DATABASE_PATH` — путь к SQLite-файлу.

## Команды

- `/start` — открыть бота.
- `/cancel` — отменить текущую заявку.
- `/help` — помощь.
- `/id` — показать chat_id текущего чата.

## Важное перед использованием с реальными клиентами

Текст согласия в примере — техническая заготовка, а не юридическая консультация. Перед сбором реальных данных разместите фактическую политику конфиденциальности и проверьте требования законодательства, применимого к агентству и его клиентам. Настройте срок хранения заявок и процедуру удаления персональных данных.

## Ограничения первой версии

- Хранилище — SQLite; для небольшого старта и тестов этого достаточно. При росте нагрузки можно перейти на PostgreSQL.
- Напоминание отправляется один раз после периода бездействия. Бот должен быть запущен, чтобы отправить его; после перезапуска незавершённые анкеты остаются в базе.
- Цены и реальные туры не подбираются автоматически: бот собирает пожелания и передаёт их менеджеру.
